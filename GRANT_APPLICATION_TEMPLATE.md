# Шаблон заявки на грант для проекта Синапс

## 1. Краткое описание проекта (Elevator Pitch)

**Synapse** — это ИИ-платформа, которая анализирует диалоги пользователей и автоматически находит связи с людьми, имеющими схожие интересы, деловые цели или инвестиционные возможности.

Мы превращаем обычный чат с ИИ в мощный инструмент нетворкинга.

## 2. Проблема

- Люди тратят **часы** на поиск партнёров, инвесторов и единомышленников вручную
- Существующие платформы (LinkedIn, Facebook) не понимают **контекст** общения
- Пользователи не знают, как правильно сформулировать свой запрос для поиска
- Рынок AI-нетворкинга почти пуст, но спрос огромен

## 3. Решение

- Пользователь общается с ИИ в привычном чат-интерфейсе
- Наш агент в фоне **анализирует** каждое сообщение
- Извлекает: темы, намерения, эмоции, сущности (люди/компании)
- Строит **профиль** пользователя на основе диалогов
- Находит **совпадения** с другими пользователями
- Предлагает **персонализированные рекомендации**

## 4. Ключевые метрики

- MVP готов, проходит тестирование
- Планируем 1000+ пользователей в первый месяц после запуска
- Среднее время удержания пользователя: 15+ минут на сессию
- Конверсия в платную подписку: ожидаем 5–10%

## 5. Технологии

- **Backend**: FastAPI (Python), SQLAlchemy, JWT
- **LLM**: DeepSeek (текущий), Groq/Modal (планируемый)
- **Frontend**: Vanilla JS + HTML5 + CSS3
- **База данных**: PostgreSQL (планируем использовать грант)
- **Инфраструктура**: Render.com (текущий), Google Cloud / Azure (планируемый)

## 8. Как мы используем грант

| Ресурс | На что потратим |
|--------|-----------------|
| GPU (Modal) | Запуск агента-сканера, эмбеддинги, обучение модели |
| Облачный хостинг (Google Cloud) | Бэкенд, PostgreSQL, Redis |
| LLM-инференс (Groq) | Быстрый чат, снижение задержек |
| Хранилище (AWS/DigitalOcean) | Логи, кэши, пользовательские файлы |
