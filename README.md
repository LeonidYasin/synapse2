# Синапс — ИИ-платформа для поиска связей

ИИ-ассистент, который анализирует ваши диалоги и находит связи с другими людьми.

## Быстрый старт

1. Клонируйте репозиторий
2. Установите зависимости бэкенда: `pip install -r backend/requirements.txt`
3. Создайте файл `.env` в папке `backend` с ключом `DEEPSEEK_API_KEY`
4. Запустите бэкенд: `python backend/run.py`
5. Откройте `frontend/index.html` в браузере
