# Гранты для проекта Синапс

## О проекте

**Синапс** — это ИИ-платформа, которая анализирует диалоги пользователей и находит связи с другими людьми (партнёры, инвесторы, единомышленники).

**Технологии:**
- Backend: FastAPI, Python
- Frontend: Vanilla JS + HTML5
- LLM: DeepSeek / Groq / Gemini
- База данных: PostgreSQL
- Агент-сканер: на базе LLM для извлечения сущностей, эмоций, намерений

**Стадия:** MVP готов, проходит тестирование

## Текст для заявок

**Краткое описание:**
Synapse is an AI-powered platform that analyzes user conversations and connects people with similar interests, business partners, and investors. Our AI agent processes chat histories to build user profiles and suggest meaningful connections.

**Проблема:**
People spend hours searching for the right partners, investors, and collaborators manually. Existing platforms (LinkedIn, Facebook) don't understand the context of conversations.

**Решение:**
We provide a chat interface where users talk to an AI, and our agent automatically analyzes their needs, extracts key topics, and finds relevant people in the system.
